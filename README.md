# Split View

치지직과 SOOP의 공개 라이브를 플랫폼 플레이어와 분리된 한 창에서 최대 네 개까지 재생하는 Chromium Manifest V3 확장입니다.

## 개발

```bash
npm install
npm run check
```

`npm run build` 결과는 `dist/`에 생성됩니다. Chrome, Edge 또는 Whale의 확장 관리 화면에서 개발자 모드를 켠 뒤 `dist/`를 압축해제된 확장으로 로드할 수 있습니다.

배포용 ZIP은 다음 명령으로 만듭니다.

```bash
npm run package
```

## 사용

1. 치지직 또는 SOOP 라이브 페이지에서 확장 아이콘을 누릅니다.
2. 현재 방송을 열거나 라이브 URL을 직접 입력합니다.
3. 최초 재생 때 표시되는 CDN 접근 요청을 승인합니다.
4. 타일을 클릭해 해당 방송으로 오디오 포커스를 이동합니다.

플레이어 단축키는 `1`–`4`, `Space`, `M`, `F`, `Shift+F`, `L`, `A`/`+`, `[`/`]`, `Esc`입니다.

## 개인정보와 제한

- 별도 서버, 원격 분석, 녹화, 다운로드, 재송출, 광고 필터링을 사용하지 않습니다.
- 재생 세션 URL, AID, 서명 쿼리와 요청 컨텍스트는 저장하지 않습니다.
- 인증·연령·구독·비밀번호·지역 또는 권리 제한을 우회하지 않습니다.
- 플랫폼의 비공개 재생 계약이 바뀌면 해당 어댑터 업데이트가 필요할 수 있습니다.

제품과 기술 결정은 [설계 문서](docs/specs/2026-08-26-split-view-design.md)에 정리되어 있습니다.
