# 플랫폼 정책 검토

검토일: 2026-08-26  
대상: Split View 0.1.0의 오픈소스 공개와 Chromium 확장 배포

> 이 문서는 제품 범위를 정하기 위한 기술·운영 검토이며 법률 자문이 아닙니다. 플랫폼의 명시적 승인이나 제휴를 의미하지 않습니다.

## 결론

Split View 자체 코드는 MIT로 공개할 수 있습니다. 다만 현재 재생 어댑터가 플랫폼의 공식 개발자 API만으로 구현된 것은 아니므로, 플랫폼이 허가한 독립 플레이어라고 단정할 수 없습니다. 공개는 다음 조건을 모두 유지하는 **위험 관리형 오픈소스**로 진행합니다.

- 비로그인 상태에서 접근 가능한 공개 라이브만 처리합니다.
- 인증·연령·구독·비밀번호·지역·DRM·권리 제한을 우회하지 않습니다.
- 광고를 탐지, 제거, 차단하거나 건너뛰지 않습니다.
- 방송을 녹화, 다운로드, 재송출, 캐시하거나 제3자에게 제공하지 않습니다.
- 쿠키, 토큰, AID, 서명된 URL을 영구 저장하거나 원격 전송하지 않습니다.
- 플랫폼 로고·BI·CI를 포함하지 않고 공식·제휴·승인을 암시하지 않습니다.
- 플랫폼이 접근 중단을 요청하거나 약관·기술 계약이 바뀌면 해당 어댑터를 비활성화할 수 있습니다.

오픈소스 라이선스가 허용하는 것은 이 저장소의 코드 사용뿐입니다. 방송 콘텐츠, 플랫폼 브랜드, API 또는 서비스 이용 권리를 재허락하지 않습니다.

## 공식 자료별 판단

### NAVER·치지직

- [NAVER 이용약관](https://policy.naver.com/rules/service.html)은 개별 서비스 약관이 우선할 수 있다고 정하고, 타인의 콘텐츠를 NAVER 서비스를 통해 이용해도 지식재산권을 취득하는 것은 아니라고 안내합니다. 허락 없는 자동화 수단을 이용한 계정·게시물·검색 정보 수집과 기술적 우회, 서비스·소프트웨어의 복제·변형·역설계도 제한합니다.
- [치지직 개발자 센터](https://developers.chzzk.naver.com/)와 [공식 API 문서](https://chzzk.gitbook.io/chzzk)는 승인된 연동 경로를 별도로 제공합니다. 공식 Open API 도메인은 `openapi.chzzk.naver.com`이지만 현재 Split View는 공개 재생 정보를 얻기 위해 `api.chzzk.naver.com/service/...` 계약을 사용합니다. 따라서 이 어댑터는 공식 Open API 연동이 아니라 변경·차단 가능한 비공식 호환 계층으로 표시합니다.
- [치지직 API 팁](https://chzzk.gitbook.io/chzzk/chzzk-api/tips)은 개발자 애플리케이션 ID·이름에 `CHZZK`, `치지직`, `NAVER`, `네이버`를 포함하지 않도록 안내합니다. 제품명은 중립적인 `Split View`로 유지합니다.
- [치지직 로고 사용 가이드](https://help.naver.com/service/30044/contents/23364?lang=ko&osType=COMMONOS)는 로고 변형과 사전 협의 없는 제휴·지원 암시, 상업적 사용을 제한합니다. 공식 로고나 변형 로고를 저장소·스토어 이미지에 포함하지 않습니다.
- 치지직은 모든 방송의 광고를 제거하는 유료 상품인 [치트키](https://help.naver.com/service/30044/contents/23333)를 운영하고 있습니다. 광고 건너뛰기를 제품 기능으로 제공하지 않습니다.
- [프라임 콘텐츠 안내](https://help.naver.com/service/30044/contents/24210?lang=ko&osType=COMMONOS)는 유료 콘텐츠의 이용 범위를 제한합니다. 프라임·구독·권리 제한 콘텐츠는 지원하지 않습니다.

판단: **주의 필요.** 공개 방송을 로컬에서 일시 재생하는 범위는 콘텐츠 수집·재배포보다 위험이 낮지만, 내부 재생 계약 사용에 대한 명시적 허가는 확인되지 않았습니다.

### SOOP

- [SOOP 이용약관](https://www.sooplive.com/policy/policy1.html)은 서비스를 본래 이용 목적 외로 이용하는 행위, 공식 클라이언트·서버·사이트 변경, 승인되지 않은 프로그램 이용·유포, 비정상적 서비스 운영과 정보의 복제·출판·방송·제3자 제공 등을 제한하며 서비스에 광고가 포함될 수 있음을 알립니다.
- [SOOP Developers 시작 안내](https://developers.sooplive.co.kr/docs/api/getting-started)는 공식 Open API 이용에 개발자 등록, 제휴 신청과 API 키 발급 절차를 제시합니다.
- [SOOP Developers 서비스 이용 정책](https://developers.sooplive.co.kr/terms)은 회사가 안내한 방법 외 접근, 무단 상표 사용, 승인 없는 수익화와 제공 정보의 무단 복제·제공을 제한합니다. 현재 어댑터는 공식 API 키 기반 연동이 아니므로 승인된 개발자 앱으로 표현하지 않습니다.
- [SOOP 브랜드 가이드](https://www.sooplive.com/policy/policy9.html)는 명시적 서면 동의 없는 플랫폼 외부 브랜드 사용을 허용하지 않고, 공식·제휴 관계로 오인시키는 사용을 금지합니다. SOOP 로고·브랜드 그래픽을 저장소와 스토어 자료에 포함하지 않습니다.

판단: **주의 필요.** 공개 방송만 로컬 재생하고 데이터를 보존·재배포하지 않더라도, 비공식 클라이언트와 헤더 조정이 약관상 명시적으로 허가된 것은 아닙니다. 플랫폼의 요청이나 집행 신호가 있으면 SOOP 어댑터를 우선 중단합니다.

### Chrome Web Store

- [프로그램 정책](https://developer.chrome.com/docs/webstore/program-policies/policies)은 단일 목적, 정확한 설명, 투명한 동작, 최소 권한과 기만적 행위 금지를 요구합니다.
- [사용자 데이터 정책](https://developer.chrome.com/docs/webstore/user_data)은 눈에 띄는 사용자 기능에 필요한 데이터만 처리하고 사용을 투명하게 공개하도록 요구합니다.
- [게시 절차](https://developer.chrome.com/docs/webstore/publish/)와 [Web Store API 안내](https://developer.chrome.com/docs/webstore/using-api)는 최초 등록·스토어 정보·개인정보 항목·2단계 인증·심사와 이후 API 자동화 절차를 설명합니다.

판단: **배포 가능.** 단일 목적과 로컬 처리는 정책에 맞지만 `https://*/*` 선택 권한은 설명이 필요합니다. 이 선언은 동적으로 배정된 CDN origin 하나를 재생 직전에 사용자에게 요청하기 위해서만 사용하고, 설치 시 일괄 부여하지 않으며 설정에서 회수할 수 있게 유지합니다.

## 기능 위험 분류

| 수준 | 기능·행위 | 처리 원칙 |
| --- | --- | --- |
| 허용 | 공개 라이브의 로컬 일시 재생, 중립적 텍스트 호환성 표기, 로컬 설정 | 유지 |
| 주의 | 비공식 재생 endpoint, 동적 CDN origin 권한, SOOP 요청 헤더 조정 | 최소화·문서화·변경 시 안전 실패 |
| 금지 | 광고 차단/건너뛰기, 인증·유료·연령·지역·DRM 우회 | 구현·기여 거부 |
| 금지 | 녹화·다운로드·재송출·세션 공유, 토큰/서명 저장 | 구현·기여 거부 |
| 금지 | 공식 로고, 제휴·승인 암시, 허가 없는 플랫폼 연동 수익화 | 사전 서면 허가 없이는 사용 금지 |

## 재검토 조건

다음 중 하나가 발생하면 릴리스 전에 이 문서를 다시 검토합니다.

- 플랫폼 이용약관, 개발자 정책, 브랜드 가이드 또는 광고 정책 변경
- 재생 API의 도메인·인증 방식·권한 모델 변경
- 로그인 정보, 계정 연동, 원격 서버, 분석, 수익화 또는 콘텐츠 저장 기능 추가
- Chrome Web Store 심사 피드백, 플랫폼의 접근 중단·삭제 요청 또는 권리자 신고
- 공식 로고·스크린샷·마케팅 자산을 사용하려는 경우

공식 재생 API가 제공되면 비공식 endpoint보다 공식 API로 이전하는 것을 우선합니다.
